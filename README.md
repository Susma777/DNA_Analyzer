# DNA Analyzer

This project analyzes DNA sequences using Python.

## Features

- Reads DNA sequence from a FASTA file
- Counts bases (A, T, G, C)
- Calculates GC content
- Finds start and stop codons
- Extracts gene sequence
- Translates DNA into protein

## Project Structure

- dna_analyzer.py
- gene.fna
- README.md

## How to Run

1. Install Python
2. Place your FASTA file (gene.fna) in the same folder
3. Run the program:

```bash
python dna_analyzer.py
